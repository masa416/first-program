# ホーム（仮）

スマホを触りすぎて時間がなくなる・普段の世界を謳歌できていない人のための、Android用ホーム画面アプリ（試作 v0.1）。

## 今入っている機能
- ホーム画面を開くと、最初にメモ帳が出る
- 画面が消えている時間を「何もしない時間」として数える（設定した寝ている時間は外す）
- スマホを開くたびに「今なに考えてた？」と聞き、答えをメモに残す
- アプリ一覧は「アプリ」ボタンの奥（1段階だけ面倒にしてある）

## スマホに入れる手順
1. このリポジトリの「Releases」から、いちばん新しい `app-debug.apk` をスマホでダウンロードする
2. 「提供元不明のアプリ」のインストールを許可して、インストールする
3. アプリを開き、「設定」から
   - 他のアプリの上に表示を許可
   - ホームアプリをこのアプリにする
   - 電池の最適化から外す
4. 元のホーム画面に戻したいときは、Androidの 設定 → アプリ → デフォルトのアプリ → ホームアプリ で選び直す

## 組み立て
`main` に push すると GitHub Actions が APK を組み立てて、Releases に置く。
